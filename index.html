🧾 Ligação com o PDV

O PDV manda cada fechamento de caixa para cá (pela planilha do PDV). Cole estes dois dados no script da planilha do PDV — o passo a passo está no guia.

📦 Trazer dados do sistema antigo

Na planilha antiga (Google), use o menu Financeiro Madora → Exportar para o sistema novo, baixe o arquivo e envie aqui. Pode enviar de novo sem duplicar nada.

Regras automáticas de categoria

Quando o fornecedor contém o texto, a despesa recebe a categoria. As regras novas são criadas pela tela de Despesas.
